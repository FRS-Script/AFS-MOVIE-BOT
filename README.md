# 🎬 AFS MOVIE BOT

Arabic Discord Movie Bot.

## Features
- 🎥 Movies currently showing in cinemas.
- 🔎 Search for movies.
- 📺 Legal streaming platforms.
- 🇸🇦 Arabic language.
- ⭐ Movie ratings and posters.

## Technologies
- Node.js
- Discord.js v14
- TMDB API

## Installation
npm install

## Start
npm start

## Environment Variables
- DISCORD_TOKEN
- CLIENT_ID
- GUILD_ID
- TMDB_TOKEN
